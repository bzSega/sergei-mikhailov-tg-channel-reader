# Repair Companion Workflow and Python Installer

**Status:** done (2026-07-18)

## Context

Pull request [#8](https://github.com/bzSega/sergei-mikhailov-tg-channel-reader/pull/8)
needed current TweetClaw installation guidance and an independently useful
repository fix. The setup script also invoked an unqualified `pip`, which could
install the package into a different Python environment than the checked
`python3` interpreter.

## Plan

- Rebase the contribution onto the current default branch.
- Update the companion workflow from canonical public sources.
- Bind installation and dependency guidance to the checked Python interpreter.
- Validate shell syntax, Python syntax, links, and the complete pull request.

## Result / outcome

The pull request now installs TweetClaw from its tracked ClawHub source, exposes
its optional tools explicitly, and includes the service disclosure. The setup
script consistently uses `python3 -m pip` and compares Python versions as tuples,
so Python 4 and later are not rejected by a Python 3 minor-version check.

## Lessons

Pair `pip` with the interpreter whose version and imports the setup checks.
